# Contributing to FreeAI Radar

Thanks for helping make the catalog more useful and accurate.

## Before opening a pull request

- Use the tool's official website as the main link.
- Describe what the tool does in your own words.
- Do not describe a tool as “unlimited” unless you can verify that claim from a current, reliable source.
- If adding a statement about price, quota, image uploads, or account requirements, provide the source and the date checked in your pull request description.
- Be clear about the difference between a free plan, a time-limited trial, an open-source tool, and software that runs a model locally.
- Avoid duplicate entries and never include API keys, access tokens, passwords, or private data.

## Where to make changes

- `data/tools.json` — add or correct tool entries.
- `app.js` — search, filters, sorting, and card rendering.
- `style.css` — visual style and responsive layout.
- `index.html` — page structure and visible copy.

## Pull request checklist

- [ ] I checked the official link.
- [ ] My description is accurate and does not promise unverified features.
- [ ] JSON syntax is valid.
- [ ] The page still works on desktop and mobile.
